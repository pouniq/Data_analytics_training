# مدرسه تابستانه تحلیل داده
یک ریپو برای تکالیفی که در مدرسه تابستانه تحلیل داده انجام شد در تابستان ۱۴۰۵.
## 1. Prompt Engineering:
توانستیم با استفاده از هوش مصنوعی یک کانال در بله به نام کهن نگار بسازیم با آیدی http://ble.ir/kohannegar.
## 2. SQL

دستورات مقدماتی SQL انجام داده شد و ۱۲ سوال مقدماتی که راجب دیتا شبیه سازی کسب و کار کهن نگار تولید شده با LLM ها، جواب داده شد.
## 3. Power BI
ساخت یک داشبورد power bi برای بررسی و تحلیل یک فروشگاه که در فولدر power bi قرار گرفته است.

## 4. Python

با استفاده از پایتون MySQL را به پایتون متصل کردیم و با استفاده از کتابخانه های pandas, numpy و matplotlib به تحلیل این داده ها پرداختیم.
